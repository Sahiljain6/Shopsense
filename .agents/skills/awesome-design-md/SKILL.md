## How to Use

When implementing a UI feature, landing page, dashboard, or component:
1. Identify the aesthetic target (e.g. "Linear-style dark mode", "Stripe-style pricing table", "Apple-style hardware showcase").
2. Read the corresponding `DESIGN.md` file under `./design-md/<brand>/DESIGN.md`.
3. Extract exact color hexes, typography scales, border radii, and CSS variables into the project's styling.

# API Documentation

FastAPI exposes Swagger at `/docs`.

- `POST /chat`: conversational shopping request.
- `POST /recommend`: returns up to three product recommendations.
- `POST /compare`: compares two to four products.
- `POST /reviews`: summarizes reviews.
- `GET /products`: catalog search.
- `GET /history`: chat history.
- `POST /wishlist`: save product.
- `POST /login`: JWT login.
- `POST /register`: account creation.
